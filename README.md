# MyWorkspace

Личное рабочее пространство для FBS-инструментов, рабочих документов и аналитических отчётов.

## Возможности

- стартовый экран с быстрыми ссылками на FBS Конвертер, FBS Сканер и Google Таблицы;
- локальная библиотека документов с готовыми шаблонами;
- конструктор аналитики с изображениями, подписями и редактируемой таблицей;
- автоматический предпросмотр отчёта;
- выгрузка в PDF через печать и в Word для последующего открытия в Google Документах;
- адаптивная версия для компьютера и телефона.

Все созданные документы и черновики хранятся локально в браузере. Проект не использует сервер, аккаунты или внешние API.

## Запуск

```bash
pnpm install
pnpm dev
```

Публичная версия разворачивается через GitHub Pages после обновления ветки `main`.
