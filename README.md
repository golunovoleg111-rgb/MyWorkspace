# MyWorkspace

Личное рабочее пространство для FBS-инструментов, рабочих документов и аналитических отчётов.

## Возможности

- стартовый экран с быстрыми ссылками на FBS Конвертер, FBS Сканер и Google Таблицы;
- локальная библиотека документов с готовыми шаблонами;
- конструктор аналитики с изображениями, подписями и редактируемой таблицей;
- автоматический предпросмотр отчёта;
- выгрузка в PDF через печать и в настоящий DOCX со встроенными изображениями для Word и Google Документов;
- настраиваемый 3D Sim-Pet: 16 пород кошек и собак, плавная четырёхлапая походка с боковым разворотом, окрасы, глаза и аксессуары;
- локальный центр питомца с диалогами без внешнего API, заботой, дыхательной паузой, домиком, уровнями дружбы и воспоминаниями;
- полноэкранный `Living Space`: интерактивная WebGL-комната с процедурными шейдерами, динамическим светом, bloom, камерой, магазином, заданиями и предметными анимациями питомца;
- режим `Bond & Play`: 3D-тренировка «Световой след», серии и награды, уровни дружбы и локальный диалог с питомцем без внешнего API;
- адаптивная версия для компьютера и телефона.

Все созданные документы, черновики и состояние питомца хранятся локально в браузере. Проект не использует сервер, аккаунты или внешние API.

## Запуск

```bash
pnpm install
pnpm dev
```

Публичная версия разворачивается через GitHub Pages после обновления ветки `main`.
